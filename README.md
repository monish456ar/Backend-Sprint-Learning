# Python Backend Sprint Learning 🚀

A structured, hands-on learning repository tracking daily Python concepts, exercises, and projects — from fundamental control flow to advanced generic architectures.

---

## 📅 Daily Learning Roadmap

| Day | Topic | Key Concepts | Directory |
| :--- | :--- | :--- | :--- |
| **Day 1** | **Python Basics & CLI** | Functions, `while` loops, user input, `try/except`, string formatting | [`day1.py`](./day1.py) |
| **Day 2** | **Data Structures & Collections** | Lists, Dicts, Sets, Comprehensions, `enumerate`, `zip`, `Counter`, `deepcopy` | [`Day2/`](./Day2/README.md) |
| **Day 3** | **Functions & Type Annotations** | Type hints, `Union` / Optional, `Callable` callbacks, type narrowing | [`Day3/`](./Day3/README.md) |
| **Day 4** | **OOP & Dataclasses** | Classes, inheritance, `super()`, `@property`, `@staticmethod`, `@dataclass` | [`Day4/`](./Day4/README.md) |
| **Day 5** | **Exceptions & Packages** | Custom exceptions, `try-except-else-finally`, Context Managers (`with`), modular packages | [`Day5/`](./Day5/README.md) |
| **Day 6** | **Advanced Typing & Generics** | `TypeVar`, `Generic[T]`, `Protocol`, `TypedDict`, `Literal`, `Final`, `@overload` | [`Day6/`](./Day6/README.md) |

## ⚡ Getting Started

This project is managed with Python 3.12+ and `uv`.

```bash
# Clone the repository
git clone https://github.com/monish456ar/Backend-Sprint-Learning.git
cd Backend-Sprint-Learning

# Run any day's exercise (e.g. Day 6)
cd Day6
python main.py
```
